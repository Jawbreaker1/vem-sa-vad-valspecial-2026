# Källmaterial för bildbyggen

Den här katalogen innehåller redigerbart källmaterial och byggproveniens som behövs för att kunna återskapa spelets sammansatta bildresurser. Filerna här publiceras inte direkt av webbappen.

- `leader-gallery/cheer-raised-arms-v2.png` är den korrigerade, transparenta jubelposen som används av spritebygget.
- `partiledargalleriet-build-manifest.json` dokumenterar beskärning, transparensbehandling, placering och utdata för partiledargalleriet.

Manifestets `imagegen://`- och `hatch-pet://`-värden betecknar externa skapandekällor som inte ligger i repot. Repo-relativa sökvägar betecknar versionshanterat material.
